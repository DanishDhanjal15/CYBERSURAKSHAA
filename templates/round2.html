Two deliberate rules: a call that returns an error is never billed, and a free tenant over quota is never cut off — during an emergency, silencing a citizen channel is worse than an unpaid bill. Both are asserted in the test suite. Revenue reads zero on a fresh install because nothing is seeded.

Shipping this took a new keyword bank and a switch — no model was retrained, no schema migrated, no route added. The bank stays inert outside an emergency because "relief fund" also appears in genuine government circulars, and every declaration is written to the tamper-evident evidence chain so a score can still be explained months later.

The whole intelligence layer — entity graph, campaign clustering, indicator extraction, evidence chain, calibration and the emergency bank — is stdlib-only. That half runs on every request at the cost of a regex. Only the vision path needs the heavy stack, and it is the path that splits off first when volume grows. The single migration that matters is SQLite → PostgreSQL, confined to one connection helper.
