# ── Intelligence layer (services/intel/) ─────────────────────
# The package itself is deliberately stdlib-only: the entity graph, campaign
# clustering, indicator extraction, evidence chain, calibration, AXML parsing
# and Hinglish normalisation all run on a bare interpreter. That is what lets
# tests/ execute in CI without downloading several gigabytes of model weights,
# and it means a failure anywhere in the ML stack degrades a detector rather
# than taking the correlation layer down with it.
#
# Two optional extras, neither of which is imported at startup:
#
#   faster-whisper   speech recognition for the voice module. Without it the
#                    module still scores analyst-supplied transcripts and says
#                    plainly that audio cannot be transcribed.
#   androguard       richer APK parsing. services/intel/apk.py falls back to
#                    its own stdlib binary-XML parser, which is what the tests
#                    exercise, so this only adds resource-table resolution.
#
# Install with:  pip install faster-whisper androguard
